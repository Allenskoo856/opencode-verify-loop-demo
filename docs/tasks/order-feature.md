# 订单功能验收任务

实现或修复订单功能，并满足以下不可修改的验收条件：

1. 未登录访问订单页面必须跳转到登录页。
2. 正确账号可以登录，错误密码显示可理解的错误信息。
3. 正确账号可以创建订单；订单标题不能为空且长度不能超过 120。
4. 订单列表显示创建时间和状态；取消后状态变为 `CANCELLED`。
5. 已取消订单再次取消必须保持幂等，不得产生第二条订单。
6. 后端 API、数据库集成测试和前端 Playwright 测试必须通过。

不要修改 `verify-controller/policy.yaml`、`.opencode/`、`e2e/specs/` 或离线校验文件来规避失败。
